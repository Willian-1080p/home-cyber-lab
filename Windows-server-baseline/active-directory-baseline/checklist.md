# Checklist de Hardening – Active Directory

## Controladores de Domínio
- [ ] DC isolado (Tier 0)
- [ ] Acesso administrativo restrito
- [ ] Backup do AD ativo

## GPO
- [ ] Password Policy aplicada
- [ ] Firewall via GPO
- [ ] Auditoria habilitada

## Credenciais
- [ ] Admins não logam em workstations
- [ ] Contas de serviço com senha forte
