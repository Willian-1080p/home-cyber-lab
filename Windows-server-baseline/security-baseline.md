# Windows Security Baseline – WillSecLab

## Controles Aplicados
- Firewall ativo por padrão
- Proteção contra malware e ransomware
- Controle de contas e senhas
- Redução de serviços expostos

## Ameaças Mitigadas
- Malware comum
- Ataques de força bruta
- Exploração de serviços legados
- Movimento lateral básico

## Limitações
Este baseline não substitui:
- GPO corporativa
- EDR profissional
- Monitoramento centralizado
