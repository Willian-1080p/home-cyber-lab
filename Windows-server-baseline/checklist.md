# Checklist de Hardening – Windows

## 🖥️ Sistema
- [ ] Sistema atualizado
- [ ] Conta administrativa protegida
- [ ] UAC ativo

## 🔐 Senhas e Contas
- [ ] Senhas com no mínimo 12 caracteres
- [ ] Bloqueio após tentativas inválidas
- [ ] Contas desnecessárias removidas

## 🔥 Firewall
- [ ] Firewall ativo em todos os perfis
- [ ] Bloqueio padrão de entrada
- [ ] Regras mínimas configuradas

## 🛡️ Windows Defender
- [ ] Proteção em tempo real ativa
- [ ] Proteção contra PUA ativa
- [ ] Controlled Folder Access ativo

## 📜 Auditoria
- [ ] Logs de segurança ativos
- [ ] Tentativas de login monitoradas
