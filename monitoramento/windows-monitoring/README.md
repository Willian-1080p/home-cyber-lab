# 🪟 Windows Security Monitoring – WillSecLab

## 📌 Descrição
Este projeto implementa **monitoramento de eventos de segurança no Windows**, focado na detecção de **tentativas de brute-force**, **atividades suspeitas** e **comportamentos anômalos** a partir dos logs nativos do sistema.

O projeto utiliza **PowerShell e Windows Event Logs**, sem dependência de ferramentas externas.

---

## 🎯 Objetivos
- Detectar tentativas de força bruta
- Identificar comportamentos suspeitos
- Aumentar visibilidade de eventos críticos
- Servir como base para SIEM e resposta a incidentes

---

## 🧠 Conceitos de Segurança Aplicados
- Detecção baseada em logs
- Auditoria de autenticação
- Monitoramento contínuo
- Princípio do menor privilégio
- Blue Team / SOC fundamentals

---

## 🛠️ Tecnologias Utilizadas
- Windows 10 / 11
- Windows Server 2019 / 2022
- PowerShell
- Windows Event Viewer
