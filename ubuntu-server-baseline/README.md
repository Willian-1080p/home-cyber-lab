# 🔐 Ubuntu Server Hardening Baseline – WillSecLab

## 📌 Descrição
Este projeto implementa um baseline de hardening para servidores Ubuntu Server, aplicando boas práticas de segurança para reduzir a superfície de ataque e fortalecer o sistema contra ameaças comuns.

Faz parte do laboratório **WillSecLab**, voltado ao aprendizado prático, ético e documentado em Segurança da Informação.

---

## 🎯 Objetivo
- Automatizar configurações básicas de segurança
- Padronizar hardening inicial de servidores Linux
- Servir como base reutilizável para ambientes reais
- Facilitar auditorias e revisões de segurança

---

## 🧠 Conceitos de Segurança Aplicados
- Princípio do menor privilégio
- Hardening de sistema operacional
- Defense in Depth
- Segurança por padrão (secure by default)
- Auditoria e rastreabilidade

---

## 🛠️ Tecnologias Utilizadas
- Ubuntu Server
- Bash
- UFW (Uncomplicated Firewall)
- OpenSSH
- Sysctl

---

## 🧪 Cenário de Teste
- Máquina virtual Ubuntu Server
- Ambiente isolado (laboratório)
- Acesso administrativo controlado
